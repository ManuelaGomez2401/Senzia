# Notas de adaptación de la página de Senzia

## Cambios realizados
- Se unificó el nombre de marca como Senzia en el título, navegación y footer.
- Se adaptaron el mensaje principal, la descripción y las secciones al enfoque de inteligencia organizacional y bienestar laboral.
- Se reemplazaron los servicios genéricos de ingeniería de datos por las cinco líneas Senzia Listen, Insights, Reports, Action y Advisory.
- Se cambió el proceso de cuatro etapas por el ciclo Escuchar, Comprender, Analizar, Actuar, Medir y Mejorar.
- Se sustituyeron los casos con métricas no verificadas por aplicaciones ilustrativas sin resultados inventados.
- Se retiraron datos de contacto ficticios.
- Se corrigió la validación del correo electrónico y se mejoró la tolerancia del JavaScript ante elementos ausentes.
- Se corrigió el comportamiento de movimiento reducido del canvas y la pausa de la animación cuando el hero no está visible.
- El formulario ahora informa que está en modo demostración y no afirma que envió datos.

## Pendientes antes de una publicación comercial
- Incorporar logotipo e imágenes definitivas.
- Conectar el formulario a un servicio real de recepción de mensajes.
- Definir y publicar datos de contacto autorizados.
- Revisar privacidad, tratamiento de datos personales y avisos legales.
- Verificar la versión final en móvil y escritorio.
