# SENZIA

**Detectar para prevenir, comprender para transformar.**

Senzia es un emprendimiento tecnológico B2B enfocado en inteligencia organizacional y bienestar laboral. Su propuesta integra herramientas digitales, inteligencia artificial y analítica de datos para apoyar a las organizaciones en la comprensión de las condiciones psicosociales del trabajo y la orientación de acciones preventivas.

## Sitio web

Página corporativa desarrollada con HTML5, CSS3 y JavaScript.

## Soluciones presentadas

- Senzia Listen: canal conversacional para escucha y orientación inicial.
- Senzia Insights: organización y análisis de información.
- Senzia Reports: presentación de hallazgos e informes.
- Senzia Action: seguimiento de acciones preventivas.
- Senzia Advisory: acompañamiento especializado.

## Ejecutar localmente

Abre `html/index.html` con Live Server desde Visual Studio Code. Las rutas relativas del HTML están preparadas para esta estructura de carpetas.

## Antes de publicar

1. Agregar los recursos gráficos definitivos a `assets/` e insertarlos en el HTML si corresponde.
2. Conectar el formulario a un endpoint real. Actualmente valida los campos, pero no envía información.
3. Revisar el contenido institucional y agregar únicamente datos de contacto oficiales.
4. Para GitHub Pages, configurar una acción de despliegue o mover `index.html` a la raíz y ajustar las rutas relativas.

## Consideraciones

La herramienta digital descrita en el sitio no sustituye evaluaciones profesionales, instrumentos oficiales ni obligaciones legales aplicables a la gestión de riesgos psicosociales.
